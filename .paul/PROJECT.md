# Project: photography-portfolio

## Description
A personal photography portfolio website with a gallery and contact form. Serves as both a professional portfolio and an ongoing photo dump, storing all future photos and projects in an aesthetic fashion.

## Core Value
Visitors can see my photography work and contact me, while the site also serves as my aesthetic photo dump for all future work.

## Requirements
