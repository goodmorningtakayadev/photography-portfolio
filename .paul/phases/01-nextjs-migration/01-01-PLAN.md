<objective>
## Goal
Convert the Vite+React SPA to a Next.js App Router project with file-based routing, preserving all existing public pages pixel-identical.

## Purpose
This is the foundation for the entire refactor. Every subsequent phase (database, auth, admin, storage) depends on having a working Next.js App Router project. The existing visual design, animations, and user experience must be preserved exactly.

## Output
- Working Next.js App Router project with pnpm
- Three public routes: / (home), /gallery, /about
- All existing components, hooks, utils, and data migrated
- TypeScript config ready (existing .jsx files coexist)
- Tailwind CSS installed alongside existing CSS
- Pixel-identical public pages
</objective>

  <files>src/app/layout.jsx, src/app/(public)/page.jsx, src/app/(public)/gallery/page.jsx, src/app/(public)/about/page.jsx, src/components/Header/Header.jsx, src/components/Footer/Footer.jsx, src/pages/Home.jsx, src/pages/GalleryPage.jsx, src/pages/About.jsx, src/components/ContactForm/ContactForm.jsx</files>
  <action>
    1. Create `src/app/layout.jsx`:
       - Root layout with `<html lang="en">`, `<body>` with font class
       - Import `./globals.css` (which chains to existing global.css)
       - Add metadata export: title, description, openGraph, twitter (port from old index.html)
       - Wrap children in the app shell div structure: `<div className="app"><Header /><main className="main-content">{children}</main><Footer /></div>`
       - Header and Footer are client components (they use hooks) — import them directly
       - Include the structured data JSON-LD via a `<script>` tag in the `<head>` section

    2. Create route page files:
       - `src/app/(public)/page.jsx`: `"use client"` directive, import and re-export Home component from `../../pages/Home`
       - `src/app/(public)/gallery/page.jsx`: `"use client"` directive, import and re-export GalleryPage from `../../pages/GalleryPage`
       - `src/app/(public)/about/page.jsx`: `"use client"` directive, import and re-export About from `../../pages/About`

    3. Replace react-router-dom in ALL components:
       - `Header.jsx`: Replace `import { Link, useLocation } from 'react-router-dom'` with `import Link from 'next/link'` and `import { usePathname } from 'next/navigation'`. Replace `const location = useLocation()` → `const pathname = usePathname()`. Update ALL references: `location.pathname` → `pathname`, `location` (in useEffect deps) → `pathname`. Change `Link to=` to `Link href=`. <!-- audit-added: Header has useEffect deps on location.pathname that become [pathname] -->
       - `Footer.jsx`: Replace `Link` import from react-router-dom with `next/link`. Change `to=` to `href=`.
       - `Home.jsx`: Replace `Link` from react-router-dom with `next/link` (`to=` → `href=`). Note: Home.jsx does NOT use useNavigate — only Link. Do not add useRouter unless needed. <!-- audit-added: corrected — source confirms no useNavigate import -->
       - `GalleryPage.jsx`: Replace `useSearchParams` from react-router-dom with `useSearchParams` from `next/navigation`. Import `useRouter` from `next/navigation`. Next.js useSearchParams is read-only — replace the 3 `setSearchParams` calls with explicit `router.replace()`: <!-- audit-added: concrete replacement patterns -->
         * `setSearchParams(cat === 'all' ? {} : { category: cat })` → `router.replace(cat === 'all' ? '/gallery' : '/gallery?' + new URLSearchParams({ category: cat }).toString())`
         * `setSearchParams({ category: 'projects', collection: collection.id })` → `router.replace('/gallery?' + new URLSearchParams({ category: 'projects', collection: collection.id }).toString())`
         * `setSearchParams({ category: 'projects' })` → `router.replace('/gallery?' + new URLSearchParams({ category: 'projects' }).toString())`
       - `ContactForm.jsx`: Replace `import.meta.env.VITE_WEB3FORMS_KEY` with `process.env.NEXT_PUBLIC_WEB3FORMS_KEY`. This is critical — Vite's import.meta.env does not exist in Next.js. <!-- audit-added: silent break without this -->
       - `About.jsx`: Check for any router imports and replace. If none, no changes needed.

    4. Add `"use client"` directive to all components that use hooks or browser APIs:
       - `Header.jsx`, `Footer.jsx` (if it uses Link client-side behavior)
       - `Home.jsx`, `GalleryPage.jsx`, `About.jsx`
       - `Gallery.jsx`, `Lightbox.jsx`, `EditorialSpread.jsx`, `CategoryFilter.jsx`, `ContactForm.jsx`
       - `useReveal.js`, `useViewCursor.js` (hooks need "use client" in files that use them, not in the hook files themselves — but since these are imported by client components, they're fine)

    5. Update barrel exports (index.js files in component dirs) if needed — these should just re-export the component.

    Avoid:
    - Do NOT change any CSS classes, styling, or component markup beyond the router swap
    - Do NOT restructure component file locations (keep src/components/, src/pages/, src/hooks/, src/utils/)
    - Do NOT convert files to TypeScript yet
    - Do NOT add `next/image` yet — keep existing `<img>` tags as-is
    - Do NOT change the data source — keep importing from src/data/photos.json
