## Key Decisions This Session

| Decision | Rationale |
|----------|-----------|
| Batch-fetch variants in JS (not SQL subqueries) | Correlated subqueries returned null with Drizzle/Neon HTTP driver |
| `revalidatePath` instead of `revalidateTag` | revalidateTag doesn't work with direct Drizzle queries (bypasses Next.js fetch cache) |
| Projects tab removed from gallery | User: "projects will have its own page and UX flow" |
| Editorial magazine layout for project detail | User chose Option C (hybrid magazine with scroll-snap spreads) |
| CSS files instead of styled-jsx | styled-jsx scoping broke all component styles at runtime |
| Homepage featured shows projects not photos | User direction — EditorialSpread reused with project cover photos |
| Mobile scroll-snap: proximity not mandatory | Audit catch — mandatory hijacks natural mobile scrolling |
